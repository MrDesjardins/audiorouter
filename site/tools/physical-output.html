01 / Understand

How it works.

The output is a destination for the branch connected to its input.

AudioRouter route→Chosen render device→Headphones / speakers

Use it in AudioRouter

  1. Choose the intended render endpoint explicitly in Properties.
  2. Wire the processed branch to it, Save and Play at a low monitoring level.
  3. Check the route meter and the chosen Windows output's volume/mute state.

What success looks like

The branch reaches that output device. Choosing an output does not select a capture device.

If it does not work

If meters move but nothing is audible, confirm the endpoint, Windows volume and physical connection. Avoid a loop back into the same captured output.

Select the node to open Properties. Click its name to rename it. While playing, supported parameter-only edits save after a short pause. For structural edits, use Save when the canvas marks a change. Enabled and Bypass are distinct live controls; see the in-app help for their behavior.

04 / Examples

Example setups.

Example 1

Listen through headphones

  1. Choose your exact headphone playback endpoint.
  2. Connect the last tool or Mixer to this output.
  3. Save and Play; confirm its input meter.
Example 2

Hear and record independently

  1. Branch the same processed tool to Physical Output and Recorder.
  2. Play to monitor; start the Recorder only when ready.

These are starting points. Compare at a comfortable monitoring level and adjust for your own source.

05 / Troubleshooting

Common mistakes.

  • Selecting an output does not connect it: add a wire.
  • Capturing the same monitor endpoint upstream can create feedback.
  • Bluetooth latency and profile changes are device dependent.
