01 / Understand

The idea, before the settings.

Recording is a separate sink; monitoring and other branches can continue independently.

Wanted branch→Recorder→Completed take → Audio File

Use it in AudioRouter

  1. Wire the branch to record into Recorder and choose/approve a recording folder before the first take.
  2. Save and Play the session, then press Record. Recording is a separate deliberate action unless Auto record is enabled.
  3. Press Stop to finalize the take, find it in Recording, and play the completed file.
  4. Check the saved file and branch before relying on a long take; set splitting only when useful.

What success looks like

Capture activity stays at Recorder; completed-file playback belongs to Audio File. Stopping finalizes the interval actually recorded.

If it does not work

If no take starts, check the approved folder, session state and connected branch. A running route alone does not mean recording is active.

Select the node to open Properties. Click its name to rename it. While playing, supported parameter-only edits save after a short pause. For structural edits, use Save when the canvas marks a change. Enabled and Bypass are distinct live controls; see the in-app help for their behavior.

02 / Explore

Make the behavior visible.

Press Record example, stop after a few seconds, then Play recording. Only that in-memory synthetic interval is replayed; there is no microphone, disk write or download.

Record example captures the synthetic source once; Stop recording ends the take and Play recording plays it back from the Audio File stage. This is not a DSP measurement or control for your running AudioRouter session.

03 / Configure

Every control, with a reason.

01

File format

format

Choose WAV 16/24-bit, WAV 32-bit float, FLAC 16/24-bit, or MP3. WAV PCM24 is the default; MP3 uses the fixed 192 kbps profile.

Range / choiceswavPcm24 · wavPcm16 · wavFloat32 · flac24 · flac16 · mp3DefaultwavPcm24

Try thisUse WAV 24-bit for an editing master or FLAC 24-bit for lossless compression.

Keep in mind MP3 splitting is unsupported in this release. No hidden limiter or normalization is applied.

02

Record automatically when Play starts

autoRecord

Starts a new recording with each session Play after you explicitly enable it. Stop saves it.

Range / choicesOn / offDefaultfalse

Try thisTurn it on for a dedicated interview session you always want to record.

Keep in mind Opening a session or importing it does not itself start recording.

03

New file every

splitMinutes

Starts another file after this duration; zero keeps one file per take subject to operational format limits.

Range / choices0 min → 240 minDefault0 min

↓ Lower / alternativeCreates shorter segments; zero selects one file per take subject to format limits.

↑ Higher / alternativeCreates longer recording segments before the next file.

Try thisChoose 30 minutes for smaller chunks during a long session.

Keep in mind Use a splitting-capable format; MP3 does not support splitting.

04

Recording folder

recordingRoot

Choose and approve the folder before your first recording. This is shared recording configuration, rather than a per-node audio parameter.

Range / choicesDepends on your selectionDefaultChoose explicitly

Try thisUse the suggested Music/AudioRouter Recordings folder or another approved local location.

Keep in mind A suggestion is not applied silently; use Use this folder.

04 / Put it to work

Start with a useful example.

Example 1

Record raw and processed voice

  1. Branch the microphone to one Recorder.
  2. Branch the processed voice chain to another Recorder.
  3. Choose the folder, Save and Play, then Record each intended branch.
Example 2

Record without headphones

  1. Connect your source through the wanted tools to Recorder.
  2. Choose and approve the folder.
  3. Save, Play, then Record; Stop saves the take.

These are starting points. Compare at a comfortable monitoring level and adjust for your own source.

05 / Get unstuck

Small details that matter.

  • No wire into Recorder means no desired source reaches it.
  • Play alone does not record unless automatic recording was deliberately enabled.
  • Removing a library entry and recycling its file are separate actions.
