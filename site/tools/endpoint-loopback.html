01 / Understand

The idea, before the settings.

Loopback observes an output device mix, unlike process capture which follows an application tree.

Windows playback mix→Endpoint Loopback→AudioRouter route

Use it in AudioRouter

  1. Choose the Windows render endpoint whose playback you want to capture.
  2. Play audio to that endpoint, then wire Loopback to your intended route.
  3. Choose a separate monitoring destination or a layout that avoids feeding captured audio back into itself.

What success looks like

The endpoint's combined playback is captured, rather than a single application's process.

If it does not work

If the signal repeats or grows, stop the route and remove the feedback path. If silent, verify where Windows is sending playback.

Select the node to open Properties. Click its name to rename it. While playing, supported parameter-only edits save after a short pause. For structural edits, use Save when the canvas marks a change. Enabled and Bypass are distinct live controls; see the in-app help for their behavior.

03 / Configure

Every control, with a reason.

No numeric settings to guess

This node is configured through the source or endpoint selection described above. No dedicated numeric property editor is exposed.

04 / Put it to work

Start with a useful example.

Example 1

Capture a playback mix

  1. Identify which playback endpoint receives the wanted apps.
  2. Use an explicitly configured loopback source for that endpoint.
  3. Send capture to a different monitor endpoint to avoid recapturing yourself.
Example 2

Choose a narrower source

  1. If you only need one app, use Application Capture.
  2. If you need a shared playback bus, use a virtual render source or an explicitly configured loopback.

These are starting points. Compare at a comfortable monitoring level and adjust for your own source.

05 / Get unstuck

Small details that matter.

  • The current Properties panel has no dedicated Endpoint Loopback endpoint picker; do not assume the Physical Output picker configures this node.
  • A desktop mix is not every output device on the PC.
