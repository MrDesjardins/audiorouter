01 / Understand

The idea, before the settings.

This is a linear amplitude control: 100% is unchanged, 50% is half amplitude, and 200% doubles amplitude. Percent is not a perceived loudness scale.

Source→Volume→Mixer → Output

Use it in AudioRouter

  1. Place Volume on the branch you want to balance before it joins other sources.
  2. Begin at 100%, then lower that branch while the other source plays.
  3. Use 0% for silence and restore the prior percentage when finished.

What success looks like

50% is half amplitude, about −6 dB; 200% doubles amplitude and needs headroom.

If it does not work

If turning this down changes the wrong sound, follow its incoming wire to confirm which branch it controls.

Select the node to open Properties. Click its name to rename it. While playing, supported parameter-only edits save after a short pause. For structural edits, use Save when the canvas marks a change. Enabled and Bypass are distinct live controls; see the in-app help for their behavior.

02 / Explore

Make the behavior visible.

Use the same phrase to compare 50%, 100% and 200%. Output changes level without changing pitch.

The example repeats until you press Stop, and control changes are heard immediately. The traces are drawn from that audio, and the line marks the moment you hear. This is not a DSP measurement or control for your running AudioRouter session.

04 / Put it to work

Start with a useful example.

Example 1

Balance game and voice

  1. Put Volume on the game branch before the Mixer.
  2. Start the game at 50% and voice at 100%.
  3. Adjust while speaking over normal game activity.
Example 2

Silent comparison

  1. Set Volume to 0% to hear the other route.
  2. Restore the exact prior percentage when finished.

These are starting points. Compare at a comfortable monitoring level and adjust for your own source.

05 / Get unstuck

Small details that matter.

  • 200% may overload the next stage.
  • 50% amplitude is about −6 dB; it is not guaranteed to sound half as loud.
