01 / Understand

The idea, before the settings.

Advanced EQ holds up to sixteen independently enabled filters. Select a band, choose among eight shapes, then set its frequency and Q. Gain applies to peaking and shelves; All pass keeps magnitude flat and changes phase.

Source→Advanced EQ→Meter → Output

Use it in AudioRouter

  1. Add a band and choose its job: Peaking for a local correction, a shelf for a broad region, or High/Low pass to remove a frequency extreme.
  2. Select that band's point or row. Set Frequency, then Q for width/resonance; use Gain only on Peaking and shelves.
  3. Toggle that band's Enabled control to compare its contribution before adding another.
  4. Inspect the combined curve and downstream headroom. Keep the fewest bands that solve the problem.

What success looks like

The selected band's shape, location and width are distinguishable from the summed response. A flat All pass magnitude can still change phase.

If it does not work

If Gain does nothing, check the filter type: pass, notch and All pass filters do not use that gain control.

Select the node to open Properties. Click its name to rename it. While playing, supported parameter-only edits save after a short pause. For structural edits, use Save when the canvas marks a change. Enabled and Bypass are distinct live controls; see the in-app help for their behavior.

03 / Configure

Every control, with a reason.

Each band has these controls. Add up to 16 bands (displayed as 1–16), select a band, then adjust its shape, frequency, Q and gain where applicable.

Choose the right shape

Every filter has a different job.

peaking

Bell-shaped boost/cut around Frequency; Gain and Q apply.

lowShelf

Boost/cut below the transition; Gain applies.

highShelf

Boost/cut above the transition; Gain applies.

lowPass

Attenuate above the cutoff; no Gain.

highPass

Attenuate below the cutoff; no Gain.

bandPass

Pass a band with unity center magnitude; Q adjusts width; no Gain.

allPass

Preserve magnitude while changing phase; Frequency and Q apply; no Gain.

notch

Remove a narrow frequency region; no Gain.

04 / Put it to work

Start with a useful example.

Example 1

Cut a narrow resonance

  1. Add a peaking point at 300 Hz.
  2. Try −3 dB and Q 2.
  3. Move frequency slowly to the problem area, then use the smallest useful cut.
Example 2

Remove low rumble

  1. Add a high-pass band around 80 Hz.
  2. Listen to lower voice notes and move the cutoff lower if they lose body.
Example 3

Explore phase

  1. Select All pass at 1000 Hz, Q 1.
  2. Notice that the magnitude curve stays flat.
  3. Compare phase or an impulse demonstration; a flat magnitude plot does not mean no processing.

These are starting points. Compare at a comfortable monitoring level and adjust for your own source.

05 / Get unstuck

Small details that matter.

  • Gain does not apply to notch, pass, band-pass or all-pass types.
  • Higher Q is more selective for bell/notch/band-pass filters, but can also add resonance in pass filters.
  • Use the available filter type and Q controls to shape a pass filter; there is no separate slope control.
