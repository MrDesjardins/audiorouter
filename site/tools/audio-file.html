01 / Understand

How it works.

Imported media is a graph source, useful for comparing settings with repeatable material.

Chosen local file→Audio File→Processing / Output

Use it in AudioRouter

  1. Choose and approve the local file in the actual Audio File inspector.
  2. Connect the player to the intended processing and output, then Save the route.
  3. Use its Play/Pause/Stop/Seek controls; compare a repeatable passage when tuning effects.

What success looks like

Pause keeps the position, Stop returns to the start, and seeking chooses a deliberate point in the file.

If it does not work

If loading fails, inspect format/path access. A browser lesson playing successfully does not prove your local file is supported.

Select the node to open Properties. Click its name to rename it. While playing, supported parameter-only edits save after a short pause. For structural edits, use Save when the canvas marks a change. Enabled and Bypass are distinct live controls; see the in-app help for their behavior.

02 / Explore

Try the example.

A built-in synthetic melody stands in for a file so you can practice play, pause and seek. No user's file is read or uploaded.

The example repeats until you press Stop, and control changes are heard immediately. The traces are drawn from that audio, and the line marks the moment you hear. This is not a DSP measurement or control for your running AudioRouter session.

In the app.

Loop in the app

Loop changes from false to true at 3.2 seconds. Repeat the imported audio when it reaches the end. The control appears briefly, then the view returns to the top visual while the synthetic audio continues. This short example shows the Loop setting; it ends before the full source repeats.

04 / Examples

Example setups.

Example 1

Tune with a repeatable phrase

  1. Import a short voice WAV or MP3.
  2. Connect it through the effect chain and to your output.
  3. Save, enable Loop and Play.
Example 2

Create a temporary voice reference

  1. Connect an existing mic or application source to an enabled Recorder.
  2. Start the session, choose that Recorder in Audio File Properties and record the take.
  3. Stop and use take, then Save the audio-file source.

These are starting points. Compare at a comfortable monitoring level and adjust for your own source.

05 / Troubleshooting

Common mistakes.

  • An imported file is not yet connected to an output.
  • Pause/Resume lives in Properties; the compact node offers Play/Stop.
  • A temporary take cannot pick or open a microphone.
