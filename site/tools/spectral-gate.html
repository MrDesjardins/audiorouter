01 / Understand

How it works.

Spectral Gate learns a noise profile, then compares each frequency region with a threshold above that profile. Reduction sets how deeply bins below the threshold are attenuated.

Noisy source→Spectral Gate→Output

Use it in AudioRouter

  1. Learn a noise-only interval, then keep the profile before evaluating speech.
  2. Start with Threshold 3 dB above the learned noise and Reduction 40 dB.
  3. Lower Threshold or Reduction if quiet syllables develop holes; relearn when the noise changes.

What success looks like

Frequency regions close to the learned background are attenuated; this differs from closing the entire signal with Gate.

If it does not work

A profile learned during speech can remove wanted frequencies. Correct the profile before applying stronger settings.

Select the node to open Properties. Click its name to rename it. While playing, supported parameter-only edits save after a short pause. For structural edits, use Save when the canvas marks a change. Enabled and Bypass are distinct live controls; see the in-app help for their behavior.

Settings.

Range / choices-20 dB → 20 dBDefault3 dB

↓ Lower / alternativeLets more frequency regions pass.

↑ Higher / alternativeBlocks more regions.

Keep in mind This is relative dB above the profile, not dBFS.

02

Reduction

reductionDb

Attenuation of frequency regions the spectral gate blocks.

Range / choices0 dB → 80 dBDefault40 dB

↓ Lower / alternativeKeeps more sound in blocked regions.

↑ Higher / alternativeMakes blocked regions quieter.

Try this40 dB is the default; try less if spectral holes are audible.

Keep in mind Threshold decides what is blocked; Reduction decides how deeply.

Learn noise

Runtime learning controlled by Learn and Keep profile actions.

Range / choicesOn / offDefaultfalse

↓ Lower / alternativeStop and keep the measured profile before evaluating speech.

Keep in mind Requires a running enabled non-bypassed tool; the profile is stored by the editor rather than typed as raw hex.

Beyond the controls

Actions & transport

Learn noise

Start while the route is running, the tool is enabled and not bypassed, and only unwanted background is present.

Stop learning and keep profile

Stores the live 64-band profile and leaves learning mode. The editor writes the bounded profile; users do not type its 128-character hexadecimal representation.

In the app.

Threshold above noise in the app

Threshold above noise changes from 3 to -20 dB at 3.2 seconds. Lets more frequency regions pass. The control appears briefly, then the view returns to the top visual while the synthetic audio continues.

04 / Examples

Example setups.

Example 1

Create a noise boundary

  1. Start the route and click Learn noise while staying quiet.
  2. Keep the learned profile.
  3. Begin at Threshold above noise 3 dB and Reduction 40 dB, then evaluate quiet speech.
Example 2

Recover a thin voice

  1. Lower Threshold above noise toward 0 dB.
  2. Reduce the attenuation depth if spectral holes remain audible.
  3. Relearn if the noise profile included wanted audio.

These are starting points. Compare at a comfortable monitoring level and adjust for your own source.

05 / Troubleshooting

Common mistakes.

  • Raising the threshold makes fewer frequency regions pass.
  • A deep reduction can create unnatural gaps in the spectrum.
