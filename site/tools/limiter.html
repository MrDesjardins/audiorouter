Limiter

Hold sample peaks below an output ceiling.

01 / Understand

How it works.

The ceiling is the target maximum sample level. Look-ahead delays the signal so the limiter can react to peaks; Release determines how reduction recovers afterward.

Processed mix→Limiter→Meter → Output

Use it in AudioRouter

  1. Put Limiter after boosts and mixing, near the end of the audible path.
  2. Start with Ceiling −1 dBFS, Lookahead 5 ms and Release 100 ms.
  3. Play the loudest expected passage and check peak limiting.
  4. Reduce upstream levels if limiting is continuous; use Compressor for routine dynamic control.

What success looks like

Occasional sample peaks are contained while most material passes. A sample-peak ceiling is not a true-peak loudness guarantee.

If it does not work

If everything sounds flattened, reduce the level feeding the limiter instead of continually lowering Ceiling.

Select the node to open Properties. Click its name to rename it. While playing, supported parameter-only edits save after a short pause. For structural edits, use Save when the canvas marks a change. Enabled and Bypass are distinct live controls; see the in-app help for their behavior.

Release

releaseMs

How quickly the processor returns after the triggering condition ends.

Range / choices10 ms → 1000 msDefault100 ms

↓ Lower / alternativeMakes recovery faster.

↑ Higher / alternativeMakes recovery slower.

Try thisTry 200 ms if 100 ms sounds abrupt.

Keep in mind Extremely quick changes can sound like pumping or distortion.

04 / Examples

Example setups.

Example 1

Catch occasional peaks

  1. Place Limiter after EQ and gain adjustments.
  2. Start with ceiling −1 dBFS, look-ahead 5 ms and release 100 ms.
  3. Watch whether it catches occasional peaks or reduces constantly.
Example 2

Keep conversational dynamics

  1. If limiting is constant, reduce upstream Gain.
  2. Use a Compressor for broad level control and reserve Limiter for peaks.

These are starting points. Compare at a comfortable monitoring level and adjust for your own source.

05 / Troubleshooting

Common mistakes.

  • A later boost can exceed this ceiling.
  • Look-ahead adds delay.
  • 0 ms look-ahead is a different reaction tradeoff, not free future knowledge.
