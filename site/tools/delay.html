01 / Understand

The idea, before the settings.

Delay moves a signal later in time. It cannot make a late source arrive earlier. Manual alignment is separate from automatic Mixer path compensation.

Earlier audio path→Sync (delay)→Aligned destination

Use it in AudioRouter

  1. Use a repeatable event such as a recorded clap to decide which path arrives early.
  2. Insert Sync on that earlier path and begin at 0 ms.
  3. Add the measured positive offset in small steps, then compare the recorded result again.

What success looks like

The entire signal arrives later with the same shape. This tool does not mix in a dry copy or create an echo effect.

If it does not work

If audio already arrives late, adding delay makes that worse. Adjust the earlier path or the other system's timing.

Select the node to open Properties. Click its name to rename it. While playing, supported parameter-only edits save after a short pause. For structural edits, use Save when the canvas marks a change. Enabled and Bypass are distinct live controls; see the in-app help for their behavior.

04 / Put it to work

Start with a useful example.

Example 1

Align audio to video

  1. Use a clap or another visible transient.
  2. If the sound arrives before the image, add a small positive delay.
  3. Recheck the recorded result after each change.
Example 2

Compare two paths

  1. Put Delay on the earlier path.
  2. Adjust in small steps while comparing the same transient.
  3. Avoid sending duplicate versions to the same speakers during normal use.

These are starting points. Compare at a comfortable monitoring level and adjust for your own source.

05 / Get unstuck

Small details that matter.

  • Delay cannot correct audio that is already later than video.
  • Do not promise that a large live delay change sounds seamless.
