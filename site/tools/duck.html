Duck

Lower this branch when another signal or a supported game phase triggers it.

Visual walkthrough11 configuration controlsSynced audio walkthrough
See how it works ↓
∿

At or above Trigger level, Duck reduces by Amount using Attack. Hold bridges short pauses and Release restores volume. A trigger with no published level for 100 ms counts as silent. Siege round mode follows Stats.cc locally; missing, unknown or stale state releases to full volume.

01 / Understand

How it works.

Put Duck on the audio that should get quieter, such as music. In level mode, choose another node as the trigger, such as a voice chain. The trigger controls level reduction but is not mixed into this branch.

Music target + voice key→Duck→Music output

Use it in AudioRouter

  1. Wire music through Duck as the target.
  2. Choose a separate voice node as the trigger; the key controls attenuation and is not mixed into Duck's output.
  3. Set Threshold so speech triggers the detector, then adjust Amount for the music reduction.
  4. Tune Attack, Hold and Release to bridge short pauses. Mix voice downstream only if you want it in the final output.

What success looks like

Music lowers during key phrases and recovers afterward. Changing music level alone should not be your speech trigger.

If it does not work

If music never ducks, verify the trigger node and its level against Threshold. If voice is missing from the final mix, connect its audible branch separately.

Select the node to open Properties. Click its name to rename it. While playing, supported parameter-only edits save after a short pause. For structural edits, use Save when the canvas marks a change. Enabled and Bypass are distinct live controls; see the in-app help for their behavior.

03

Attack

attackMs

How quickly the target is lowered when the separate trigger crosses Threshold.

Range / choices1 ms → 500 msDefault20 ms

↓ Lower / alternativeMakes engagement faster.

↑ Higher / alternativeMakes engagement slower.

Try thisTry 10 ms for prompt lowering at the start of a phrase.

Keep in mind For Gate this is opening; for Compressor and Duck this is increasing attenuation.

04

Hold

holdMs

How long target attenuation remains after the trigger falls below Threshold.

Range / choices0 ms → 2000 msDefault300 ms

↓ Lower / alternativeAllows disengagement sooner.

↑ Higher / alternativeBridges longer gaps.

Try thisTry 300 ms to bridge short speech pauses.

Keep in mind Release follows the hold interval.

05

Release

releaseMs

How gradually target volume recovers after the trigger and Hold end.

Range / choices20 ms → 5000 msDefault500 ms

↓ Lower / alternativeMakes recovery faster.

↑ Higher / alternativeMakes recovery slower.

Try thisTry 500 ms for a smooth return of music.

Keep in mind Extremely quick changes can sound like pumping or distortion.

04 / Examples

Example setups.

Example 1

Put speech over music

  1. Place Duck on the music branch.
  2. Select your microphone or processed voice as Triggered by.
  3. Set Trigger level between room noise and speech; start with Amount 6 dB, Attack 20 ms, Hold 300 ms and Release 500 ms.
Example 2

Prevent pumping between words

  1. Increase Hold if music returns between syllables.
  2. Lengthen Release if the return is too abrupt.
  3. Check that room noise alone does not engage the trigger.
Example 3

Follow Siege phases

  1. Choose the Siege round trigger and run the configured Stats.cc local feed.
  2. Tick the phases to turn down: menu, preparation and between rounds by default, or In a round, playing to quiet music while you play.
  3. Check the feed state; unticked phases and an unavailable feed play at full volume.

These are starting points. Compare at a comfortable monitoring level and adjust for your own source.

05 / Troubleshooting

Common mistakes.

  • Put Duck on the sound being reduced, not accidentally on the voice trigger.
  • 6 dB is approximately half amplitude; perceived loudness is not a fixed fraction.
  • Stats.cc integration is a specific local dependency, not general application detection.
