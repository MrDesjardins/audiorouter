01 / Understand

The idea, before the settings.

A Mixer adds its inputs. Each source has its own 0–100% volume, allowing balance without changing the source elsewhere in the graph. A single loud source and several moderate sources can both overload a sum.

Drums/bass + bell melody→Mixer→Meter → Output

Use it in AudioRouter

  1. Connect each wanted source to the same Mixer; its input rows follow the upstream connections.
  2. Play sources separately to identify their rows, then set their individual volumes.
  3. Play both together and check the summed output. Lower the inputs if their combined peaks overload the next stage.

What success looks like

Both different tracks are audible in Output and each volume changes only its own contribution. 100% + 100% can exceed available headroom.

If it does not work

If one fader appears ineffective, listen to that input reference alone and verify its wire/source is active.

Select the node to open Properties. Click its name to rename it. While playing, supported parameter-only edits save after a short pause. For structural edits, use Save when the canvas marks a change. Enabled and Bypass are distinct live controls; see the in-app help for their behavior.

02 / Explore

Make the behavior visible.

A syncopated drum-and-bass track and a higher bell melody have different rhythms and spectra. Set either fader to zero to isolate the other; both raw input waveforms stay visible.

04 / Put it to work

Start with a useful example.

Example 1

Blend voice and application audio

  1. Connect voice and application sources to the Mixer.
  2. Keep voice at 100% and start application input at 50%.
  3. Listen during simultaneous activity and lower levels if the combined peaks overload.
Example 2

Keep a source on an independent branch

  1. Use the Mixer input level to lower it only in this mix.
  2. Keep a separate source output connection for its other destination.
  3. Check that a destination is not also receiving an unintended duplicate route.

These are starting points. Compare at a comfortable monitoring level and adjust for your own source.

05 / Get unstuck

Small details that matter.

  • 100% on every input does not guarantee a safe sum.
  • Mixer input volume is capped at 100%; use Gain or Volume upstream for deliberate boost.
