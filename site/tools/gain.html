01 / Understand

The idea, before the settings.

Gain multiplies every sample by the same amount. A change of +6 dB is roughly twice the signal amplitude; −6 dB is roughly half. It does not make loud and quiet moments more alike.

Source→Gain→Meter → Output

Use it in AudioRouter

  1. Connect Gain before the stage that needs more headroom, then add a Meter downstream.
  2. Start at 0 dB. Play a representative loud passage and reduce Gain by 3–6 dB if the next stage is overloaded.
  3. Compare at the same monitoring volume. Increase only while the downstream peak has room.

What success looks like

The level changes while rhythm and tone stay the same. A −6 dB cut roughly halves sample amplitude.

If it does not work

If distortion remains after a cut, inspect the source and earlier stages: attenuation cannot restore samples already clipped.

Select the node to open Properties. Click its name to rename it. While playing, supported parameter-only edits save after a short pause. For structural edits, use Save when the canvas marks a change. Enabled and Bypass are distinct live controls; see the in-app help for their behavior.

04 / Put it to work

Start with a useful example.

Example 1

Match two sources

  1. Play one source at a time.
  2. Start at 0 dB and cut the louder source until the meters are comparable.
  3. Listen at the same monitoring volume.
Example 2

Create headroom

  1. Put Gain before a boosted EQ or a Mixer.
  2. Try −6 dB before the next stage.
  3. Watch peaks downstream; a source already clipped cannot be repaired by turning it down.

These are starting points. Compare at a comfortable monitoring level and adjust for your own source.

05 / Get unstuck

Small details that matter.

  • Boosting Gain cannot restore clipped audio.
  • Equal amplitude does not guarantee equal perceived loudness.
