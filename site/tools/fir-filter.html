01 / Understand

The idea, before the settings.

Choose an impulse response WAV or MP3. AudioRouter uses up to the first two seconds, normalizes it to unit energy, and convolves it with the input. Wet mix blends the filtered result with an equally delayed dry path; Output gain sets the final level. Without a selected file, the node passes audio unchanged.

Source→FIR Filter→Meter → Output

Use it in AudioRouter

  1. Choose and approve an impulse-response WAV in the actual FIR inspector.
  2. Wait for the prepared response and inspect its duration, partitions and fixed latency.
  3. Begin with Wet 100% and Gain 0 dB. Compare against dry at matched loudness, then blend if useful.
  4. If loading fails, inspect the file/error before saving the intended route.

What success looks like

The source is convolved with the loaded response. Wet/Dry blends aligned paths; output Gain adjusts the result.

If it does not work

A long or strongly colored response can smear attacks or increase level. Check the IR and headroom before blaming the source.

Select the node to open Properties. Click its name to rename it. While playing, supported parameter-only edits save after a short pause. For structural edits, use Save when the canvas marks a change. Enabled and Bypass are distinct live controls; see the in-app help for their behavior.

04 / Put it to work

Start with a useful example.

Example 1

Explore a supplied response

  1. Choose a WAV impulse response you have permission to use.
  2. Start Wet mix at 100% and Output gain at 0 dB.
  3. Compare bypass, then lower Wet mix for a blend.
Example 2

Match loudness

  1. With a selected response, compare the same passage through and around the tool.
  2. Use Output gain to reduce an unexpectedly loud result.
  3. Watch downstream peaks as well as perceived loudness.

These are starting points. Compare at a comfortable monitoring level and adjust for your own source.

05 / Get unstuck

Small details that matter.

  • A song file is not usually a useful impulse response.
  • Only the first two seconds are used.
  • Unit-energy normalization does not guarantee matching perceived loudness.
