01 / Understand

How it works.

Connect one source to A and another to B. The selected side is heard at the single output. Switching crossfades rather than cutting abruptly.

Input A + Input B→Input Switch→Output

Use it in AudioRouter

  1. Connect the two alternative sources to the switch.
  2. Choose the source to hear and select a fade suitable for the transition.
  3. Switch while both sources are active and listen through the whole fade.

What success looks like

One source replaces the other through a transition; this is not a permanent sum like Mixer.

If it does not work

If the chosen input is silent, check its incoming source before repeatedly switching.

Select the node to open Properties. Click its name to rename it. While playing, supported parameter-only edits save after a short pause. For structural edits, use Save when the canvas marks a change. Enabled and Bypass are distinct live controls; see the in-app help for their behavior.

04 / Examples

Example setups.

Example 1

Alternate two programs

  1. Connect program one to A and program two to B.
  2. Choose A, then B during playback.
  3. Use Normal for a deliberate transition.
Example 2

Make a slower handoff

  1. Choose Slow, or use the canvas Shift-click action.
  2. Switch once and allow the two-second fade to complete.

These are starting points. Compare at a comfortable monitoring level and adjust for your own source.

05 / Troubleshooting

Common mistakes.

  • Input Switch is not a Mixer: it does not keep both inputs at full volume.
  • Selecting an unconnected side produces silence.
