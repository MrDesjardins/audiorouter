Pause and replay recent live audio.

The Rewind buffer is preallocated for 10–120 seconds. Pause outputs silence. Jumps are bounded by available recorded audio. Live adds no intentional delay; jumps and resumes fade in over 256 samples.

01 / Understand

The idea, before the settings.

A rolling in-memory buffer keeps the most recent input. You can pause output while recording continues, replay earlier audio, and return to the live edge. This is temporary transport history, not a completed recording file.

Live source→Time Shift→Output

Use it in AudioRouter

  1. Set a buffer long enough for the history you need and start the route.
  2. Let history accumulate, then Pause or seek within the available range.
  3. Resume from history and use the live-edge action when you want current audio again.

What success looks like

The source keeps advancing while playback reads retained history. History before the retained window is unavailable.

If it does not work

If you cannot seek far enough back, check buffer capacity and how long the route has run.

Select the node to open Properties. Click its name to rename it. While playing, supported parameter-only edits save after a short pause. For structural edits, use Save when the canvas marks a change. Enabled and Bypass are distinct live controls; see the in-app help for their behavior.

Beyond the controls

Actions & transport

Pause

Silences output while input continues into the rolling buffer.

Resume

Continues from the retained playback position with a short fade-in.

Jump back 10 seconds

Moves toward earlier retained audio, bounded by available history.

Jump forward 10 seconds

Moves toward newer retained audio, bounded by the live edge.

Live

Returns to the current input.

04 / Put it to work

Start with a useful example.

Example 1

Catch a missed moment

  1. Start the route and let some audio accumulate.
  2. Click Jump back 10 seconds.
  3. Click Live when you want the current input again.
Example 2

Pause without losing the immediate past

  1. Click Pause; the output becomes silent while input history continues.
  2. Click Resume to continue behind the live edge.
  3. Return Live before the rolling history you need is overwritten.

These are starting points. Compare at a comfortable monitoring level and adjust for your own source.

05 / Get unstuck

Small details that matter.

  • A buffer cannot replay audio from before the route started.
  • The rolling buffer is not a permanent recording.
  • Stop frees the buffer once no running graph uses it.
