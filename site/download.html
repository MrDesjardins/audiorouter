Why it costs money

Free software, one real expense.

AudioRouter is building its own virtual cable, so you will not need a separate cable driver to send your voice or game audio to Discord, OBS or any other app.

Windows only installs audio drivers that Microsoft has signed, and Microsoft requires an EV code-signing certificate for every driver submission. That certificate is the project's one recurring cost: a few hundred dollars a year, plus a hardware key or signing service.

Everyone gets the same free software: there are no paid features and no priority support.

Where the money goes

  • The EV code-signing certificate and its yearly renewal.
  • The secure key storage the certificate requires.
  • Anything beyond the goal: future renewals and project costs.

One-time contributions help right away with the first purchase. Progress is shown on the GitHub Sponsors page, with a short update once the certificate is bought.

Install in a minute

Three steps to your first route.

Previews are not code-signed yet, so Windows asks you to confirm the installer once.

  1. 1

    Run the installer

    If Windows shows Windows protected your PC, choose More info → Run anyway. AudioRouter installs for your account only.

  2. 2

    Allow device access

    Open AudioRouter and allow it to use your audio devices once. It never changes your Windows default devices.

  3. 3

    Build a route

    Place an input and an output, connect them and press Play. The manual walks through it.

Routing to Discord or OBS today uses an existing virtual cable such as VB-Cable, until AudioRouter's own free virtual cable is signed and released.
