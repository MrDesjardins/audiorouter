# 0.0.7 experimental release

Windows 11 x64 / MSVC, 2026-10-03. User asked to fix the remaining 0.0.6
issues and ship a follow-up release, then to name the busy device in the
"in use by another application" error. No private configuration, token,
audio or support logs in the source or package.

## Scope

- Busy-device message names the exact endpoint: `ControlError::Audio`
  `resource_ids` → `resourceIds` for multi-input render and physical capture
  opens; UI maps it to the device name with the exclusive-mode remedy. Logs
  unchanged (no device names).
- Seven stale Edge tests, the double-answer route handler, screenshots
  written into `docs/`, and the PowerShell 5.1 draft-script failure fixed.
- Version 0.0.7 in all manifests and both locks. A blanket replacement first
  bumped the third-party `dtor-proc-macro` (genuinely 0.0.6) in
  `src-tauri/Cargo.lock`; restored, and the lock diffs now change only the
  22 `audiorouter-*` entries (11 per lock).
