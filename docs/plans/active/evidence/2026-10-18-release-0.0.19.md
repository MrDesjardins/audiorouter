# Release 0.0.19 — unsigned experimental app-only prerelease

The owner requested a new release on 2026-10-18 ("Can we have a new release
with the new tool we did?") and chose to run it at full speed while not in a
call. Windows x64, Rust 1.96.0. Scope DSP-20, DSP-19, NFR-06, DIST-01–08:
same app-only profile as 0.0.18 (no driver/helper payload, no host driver
install, no default-device changes). Keep 0.0.18 and compatible
configuration/recording backups for rollback. Full M08 consumer gates
remain open.

## Contents since 0.0.18

See [release notes](../../../operations/release-notes.md) (0.0.19 section).
Product changes: Fun Voice Changer tool, Duck "In a round, playing" phase,
once-a-minute `audioHealth` backend log records (`eca5152f`). Tests and
docs: saved-session starvation harness (`bf344540`), two load-sensitive UI
tests fixed (`94186755`). Website-only: silent filter guides in Firefox
(`9f7134a8`, already deployed). Known issue carried in the notes: lasting
static after heavy load, not reproduced in testing (active plan).

Compatibility: sessions holding `funVoiceChanger` nodes or the `duckAction`
Duck parameter fail validation in 0.0.18, so a rollback needs a backup taken
before such edits. No storage migration.
