# Pass-through Meter qualification

Scope: DSP-01, GRAPH-02/10, UI-04/07, API-01/12. Windows x64,
synthetic generated audio only; no microphone recording or endpoint opening.

Meter now has matched input/output ports and is offered by connection insertion.
Legacy input-only saved meters remain readable and have an explicit output
upgrade; adding the port does not create downstream connections automatically.
The engine remains sample-preserving. Current block sample peak is separate
from cumulative held peak, which retains the existing `peakDb` API meaning.
RMS is the most recent processed block's RMS, not integrated loudness.

Properties has 260 px channel bars, a calibrated -60 to +6 dBFS scale,
current/held peak markers, headroom, per-channel clipped samples, clipped time
and clipped share. Above-full-scale samples count as clipped. Time equals
channel count / processing sample rate; it does not measure a continuous event
and channel times can overlap. These are sample peaks, not true peak or LUFS.
Reset clears the prepared Meter's statistics through `meters.reset` with
SessionControl authorization, without a graph revision, save or audio restart.
Statistics also restart when the prepared graph is replaced.
