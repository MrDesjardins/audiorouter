a new-version notice, then commit, push and a new release. No private

(UI-18, PROD-06 amended); 44.1/96 kHz devices in multi-path sessions
(Windows resampling); API request builder (HTTP-08) with Duck trigger in the
catalog; surround to speakers (RACE) and Room (CAP-14); VB-Cable "16ch" twin
in the busy-device message; autosave test fix; Siege chain simulation tool
(not shipped in the app). Version 0.0.8 in all manifests; lock diffs change
only the 22 `audiorouter-*` entries (bumped by package name).
