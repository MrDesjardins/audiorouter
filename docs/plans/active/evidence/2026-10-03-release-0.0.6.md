# 0.0.6 experimental release

Windows 11 x64 / MSVC, 2026-10-03. User requested a new release after the
device-picker support fix. No private configuration, token, audio or support
logs in the source or package.

## Scope

Fixes since 0.0.5: device pickers no longer show a borrowed endpoint for a
node without one (friend's "Choose the device for …" report); drag-to-canvas
works in the desktop shell (`disable_drag_drop_handler`); dynamics/Duck
suggestion slot no longer shifts the panel (UI-17) with improved compressor
and gate suggestions. Also the Siege footstep EQ analysis tools and plan
(`tools/siege-eq`, not shipped in the app). Version 0.0.6 synchronized across
Rust/Tauri/UI/contracts manifests and both Cargo locks (45 occurrences).
