# Release 0.0.17 — unsigned experimental app-only prerelease

The owner requested a new release on 2026-10-16 ("Let's create a new release
version also and push it"). Windows x64, Rust 1.96.0. Scope NFR-06,
DIST-01–08, UI-17: same app-only profile as 0.0.16 (no driver/helper payload,
no host driver install, no default-device changes). Keep 0.0.16 and
compatible configuration/recording backups for rollback. Full M08 consumer
gates remain open.
