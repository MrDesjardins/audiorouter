# AudioRouter 0.0.27

This release includes the changes merged since 0.0.26 and tested by the owner
in the November 4 local build.

- **Check your setup before Play.** Status identifies missing devices, channel
  mismatches, feedback loops and cables running at the wrong sample rate, with
  a suggested fix. Scripts and assistants can run the same setup check.
- **Safer session editing.** Unsaved edits are protected when changing sessions
  or when another client changes the active session. Deleting a session also
  clears the backend's active target correctly.
- **Recording fixes.** MP3 recordings can be renamed, and renaming a recording
  keeps its actual file format.
- **More reliable network and plugin audio.** Paired network playback fixes
  address starvation and queued-frame accounting. Plugin handling follows
  latency changes and protects voice paths when an effect fails to process.
- **Clearer controls and assistant setup.** Save actions, contrast and tool
  icons are clearer. MCP setup explains local, Cowork and ChatGPT connections,
  permissions and connection problems. Default MCP tools cover the public API.
- **Installer and maintenance.** Windows installer investigation and
  standard-user VM qualification are recorded; dependencies and the website
  documentation have also been updated.

Windows 11 x64. The app and installer are unsigned. This remains an experimental
app-only prerelease, not a fully M08-qualified consumer release. It does not
include or install an AudioRouter virtual audio driver or change Windows default
audio devices. Existing compatible audio endpoints are required for routing.
WebView2 must be present or installed by setup.

Close AudioRouter before upgrading. Back up configuration and recordings and
retain the 0.0.26 installer for rollback with a compatible backup. No intended
session/database format migration is introduced by this version bump.

The owner's successful local test and prior Windows CI do not replace the full
hardware, long-run continuity, commercial-plugin, accessibility or first-time-user
qualification matrix. Missing-WebView2 and the complete install/upgrade/rollback
matrix remain open; prior VM evidence applies only to the tested candidate.
Known installer limitation: invoking `/repair` on the 0.0.26 VM candidate waited
for UI and was terminated; silent same-version reinstall passed instead. This
release does not claim to fix or qualify that repair path.
Latency varies by device, driver and plugin; no new latency measurement is claimed.
