# Release 0.0.18 — unsigned experimental app-only prerelease

The owner requested a new release on 2026-10-17 ("Can you publish a new
version with all these fixes?"). Windows x64, Rust 1.96.0. Scope NFR-06,
DIST-01–08, UI-17: same app-only profile as 0.0.17 (no driver/helper
payload, no host driver install, no default-device changes). Keep 0.0.17
and compatible configuration/recording backups for rollback. Full M08
consumer gates remain open.

## Contents since 0.0.17

See [release notes](../../../operations/release-notes.md) (0.0.18 section).

status, help links to the public guides and the gated Virtual Cables panel
(`ec231406`); cable route reconnect after a lost lease (`41a620db`); cable
status cached until an endpoint change (`d0a2298a`); routine-read responses
not decoded by the logger (`e3d481f7`). Website-only: tool guide player and
pictures (`0a959d5c`, already deployed).
