# AudioRouter 0.0.29

This release makes VST plugins dependable and corrects the delay that built up
between audio devices over a long session. It also includes the audit repairs
and UI improvements merged since 0.0.28.

## Plugins

- **Plugin windows open without crashing.** Some VST2 plugins (Pitchproof)
  stopped their worker as soon as Open plugin window was pressed. Plugins are
  now loaded on their window's thread.
- **A failed plugin says why.** The plugin's health box shows a "Why:" line,
  and the backend log names failed plugins, with file paths removed.
- **A mono plugin after a stereo Mixer plays.** Routes such as a stereo mic →
  Mixer → mono plugin were refused with "path 1 … is not supported".
- **Plugin Properties start with adjusting the plugin:** the plugin window
  button and its sliders come first, the wording says "Press Play", and
  recovery after a plugin update moved into its own closed section.
- **VST2 and VST3 reliability:** an empty VST2 chunk saves, large libraries and
  linked folders scan, slow plugins get longer deadlines, limits match real
  plugins, errors can be copied, and a plugin can recover after an update.

## Audio

- **Less delay, and no build-up over a long session.** Every audio device runs
  on its own clock. Outputs now hold about 20 ms instead of drifting to
  50–60 ms, and inputs stay current. The correction occasionally plays a
  2.7 ms block one sample shorter or longer, which is not audible.
- **A stall no longer leaves lasting delay.** The audio that piled up behind a
  stall is discarded once, and extra output margin is given back after five
  quiet minutes.
- **The log names the device that stalled** (`audioHealth` per input and
  output; see `docs/operations/audio-health-log.md`).

## Repairs and UI

- **Audit repairs:** Soundboard and FIR media references are kept, invalid
  sessions are quarantined without losing data, recordings finish after audio
  stops, the stereo Limiter's linked detection is corrected, and inserting or
  removing a tool keeps ports, Mixer volumes and disabled links.
- **New versions:** Settings shows the last check, the next attempt and a
  Check now button, retries a missing connection, and offers stable-only or
  stable and prerelease. It still only opens the release page.
- **Start at sign-in** is one checkbox that takes effect at once.
- **Compare by ear** says how many tools the second button leaves out and names
  them in route order. **Apps** shows the Discord and OBS logos. The Mic test
  card has its space back on Status.

Windows 11 x64. The app and installer are unsigned. This is still an
experimental app-only prerelease, not a fully M08-qualified release. It does
not include or install an AudioRouter virtual audio driver, and it does not
change Windows default audio devices. WebView2 must be present or installed by
setup.

Close AudioRouter before upgrading. Back up your configuration and recordings,
and keep the 0.0.28 installer for rollback. This version does not change the
session or database format.

Not yet qualified for this release: the full hardware matrix, long-run
continuity, accessibility, and install/upgrade/rollback on a clean machine.
The known `/repair` installer limitation from 0.0.26 remains.
