# Release 0.0.20 — unsigned experimental app-only prerelease

The owner requested a release on 2026-10-19 ("potentially we should do a
0.0.20 since it fixes the issue with the buffer increasing") and chose to
run it at full speed with AudioRouter closed. Windows x64, Rust 1.96.0.
Scope NFR-06, DIST-01–08: same app-only profile as 0.0.19 (no driver/helper
payload, no host driver install, no default-device changes). Keep 0.0.19
for rollback. Full M08 consumer gates remain open.
