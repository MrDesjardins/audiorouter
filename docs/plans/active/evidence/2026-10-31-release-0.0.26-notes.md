# AudioRouter 0.0.26

## Changes

- **Soundboard fixes.** Source meters and connection animation now follow the
  playing sounds. Random sets expand library categories. Drag audio files onto
  the Soundboard to upload them into slots. The picker and Properties editor
  handle category-only slots and compact layouts more clearly.
- **Stream Deck titles.** Sound keys respect your native Stream Deck title,
  then a per-key name, then the sound caption or filename. The numbered fallback
  no longer appears alongside a chosen title.
- **Source routing.** Native generator sources use the engine's source
  classification consistently, including Mixer layouts. Installer checks guard
  the bundled sound library in both packaging profiles.
- **Tool guides.** Portrait Properties recordings cover the remaining EQ bands
  and Soundboard controls. Clips follow panel order, describe the demonstrated
  setting and include tested Firefox playback.

## Before installing

Download `AudioRouter_0.0.26_x64-setup.exe`. It includes the desktop app and
backend, CLI/MCP, plugin workers, Stream Deck plugin and 105 bundled sounds.
For Stream Deck, use **API > Install Stream Deck plugin** in AudioRouter.

Windows 11 x64. Unsigned experimental app-only prerelease; Windows may display
a trust warning. No AudioRouter driver is included or installed. Close the
running app before upgrading. No database/session migration is intended. Back
up your configuration and recordings, and keep the 0.0.24 installer or your
previous local test package for rollback.

## Validation limits

Combined Windows Rust/UI tests, formatting, Clippy, source/processor combinations
and guide checks passed before the version bump. The local static package passed
installer payload/hash/import checks and a native library/editor/HTML5-drop
smoke. Final tagged-package results are recorded separately in the release
evidence. Synthetic HTML5 drop is not a real Explorer drag test. Normal packaged
Play/Stop, live audio continuity, final Stream Deck hardware checks, installer
execution, clean-machine upgrade/uninstall, missing WebView2 and accessibility
qualification remain open. This prerelease does not claim full M08 qualification.
