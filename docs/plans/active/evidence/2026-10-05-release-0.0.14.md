# 0.0.14 experimental release

Windows x64 / MSVC, 2026-10-05. User request: merge
`claude/zealous-archimedes-fz1lbv` (one installer that carries the Stream
Deck plugin, fewer release assets; authored on Linux), confirm it builds on
Windows, and release it. Requirements: DIST-01–08. No data migration, driver
installation or audio-device change; the virtual-cable driver work in `main`
is source only and is not packaged. Rollback: 0.0.13 with compatible
configuration/recording backups.
