# 0.0.12 experimental release

Windows x64 / MSVC, 2026-10-04. User authorized publication with Stream Deck
changes and pushing all code to main. Requirements: HTTP-07/09, AUTO-15,
UI-17, DIST-01–08. No data migration, driver installation or audio-device
change. Rollback: 0.0.11 with compatible configuration/recording backups.

## Validation and limitations

- UI: 477 tests pass; TypeScript typecheck passes.
- Shell: 60 pass, 1 ignored (`target/release-012-shell.log`).
- Stream Deck: 26 tests pass (including Record), typecheck and Elgato
  validation/packing pass; independent plugin version 0.1.0.0 retained.
- Contracts: 121 methods / 34 kinds / 18 processors / 22 event categories
  match; contracts typecheck and documentation check pass.
- Production Edge: 27 pass (`target/release-012-production-final.log`).

  trace files after an overlapping production run cleared the shared output
  directory. Final full run uses a separate output path.
- `cargo fmt --all -- --check` reports existing formatting differences
  across committed Rust files. No broad formatting rewrite included.
- Lockfile version diffs affect only 22 AudioRouter package entries.
