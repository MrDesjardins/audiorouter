# Release 0.0.21 — unsigned experimental app-only prerelease

The owner asked on 2026-10-22, before going to sleep, for a review, one PR
with all the work, its merge, and a new release "so people can use all the
fixes and new features". Windows x64, Rust 1.96.0. Scope NFR-06,
DIST-01–08: same app-only profile as 0.0.20 (no driver/helper payload, no
host driver install, no default-device changes). Keep 0.0.20 for rollback.
Full M08 consumer gates remain open.

See [release notes](../../../operations/release-notes.md) (0.0.21 section).

thread, Wave Link parity features, dependency updates), then:
