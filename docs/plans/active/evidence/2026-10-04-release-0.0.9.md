# 0.0.9 experimental release

Windows 11 x64 / MSVC, 2026-10-04. User asked to commit and release the mono
input and memory changes. No private configuration, token, audio or support
logs in the source or package.

## Scope

Input Device `channelMode` (stereo/mono/left/right, CAP-03) folded into the
input's outgoing matrices at compile; meter-only diagnostics refreshes kept
out of App state (`ui/src/liveTelemetry.tsx`). Feature commit `d4f46a11`.
Version 0.0.9 in all manifests; lock diffs change only the 22 `audiorouter-*`
entries (bumped by package name, names listed and checked).

## Open gates and rollback

Mono input needs a by-ear check on a stereo interface. Full M08 gates remain
open. Retain v0.0.8 and compatible backups; no data migration or
device-format change (an unknown `channelMode` is rejected by 0.0.8, so a
session saved with the new setting needs the setting removed before
downgrading).
